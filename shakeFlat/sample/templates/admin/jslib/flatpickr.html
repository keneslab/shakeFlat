Common Options Reference
Option Type Description
dateFormat String Format of the date (e.g., "Y-m-d", "d/m/Y", "F j, Y")
enableTime Boolean Enable time picker
noCalendar Boolean Hide calendar, show time picker only
mode String "single" (default), "multiple", "range"
inline Boolean Display calendar inline (always visible)
minDate Date/String Minimum selectable date
maxDate Date/String Maximum selectable date
disable Array Dates to disable
locale String Localization (e.g., "ko", "en", "ja")
time_24hr Boolean Use 24-hour time format
weekNumbers Boolean Show week numbers
altInput Boolean Show alternate input format
defaultDate Date/String Default/pre-filled date
