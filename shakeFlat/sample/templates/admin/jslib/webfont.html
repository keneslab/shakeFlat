sfUI 웹폰트 주입 기능

sfUI에 새로 추가된 웹폰트 주입 기능을 사용하면 동적으로 웹폰트를 로드하고 관리할 수 있습니다.

이미 프로덕션에 적용됨
  • layout.html (13-19줄): 웹폰트 사전 로드 (preconnect, Font Loader)
  • layout.html (33-34줄): sfUI 라이브러리 로드
  • template-admin.js: 테마 관리 (sfThemeManager)
  • template-admin.css: CSS 변수를 통한 테마 스타일 정의
주요 기능:
  • Google Fonts 또는 외부 CSS 파일에서 폰트 로드
  • 로컬 폰트 파일 (WOFF2, WOFF, TTF 등) 로드
  • 여러 폰트를 한 번에 로드
  • 폰트 로딩 상태 확인
  • 폰트 로딩 완료 대기
참고: 모든 예제는 sfUI Core에 내장된 sfUICore 객체를 사용합니다.
예제 1: Google Fonts 로드

Google Fonts API를 사용하여 웹폰트를 동적으로 로드합니다.

이 텍스트는 Noto Serif KR 폰트로 표시됩니다. (세리프 명조체)
This text will be displayed in Noto Serif KR font.
코드 예제
// Google Fonts 로드 - 명조체(세리프)
sfUICore.loadFont({
    family: 'Noto Serif KR',
    src: 'https://fonts.googleapis.com/css2?family=Noto+Serif+KR:wght@400;700&display=swap'
}).then(() => {
    console.log('Google Font loaded!');
    document.getElementById('google-font-demo').style.fontFamily = 'Noto Serif KR';
});
예제 2: 로컬 폰트 파일 로드

서버에 저장된 로컬 폰트 파일을 직접 로드합니다. WOFF2, WOFF, TTF 등 다양한 형식을 지원합니다.

이 텍스트는 Black Han Sans 폰트로 표시됩니다. (굵은 고딕체)
Black Han Sans는 강한 임팩트를 주는 서체입니다.
코드 예제
// Google Fonts 로드 - 굵은 고딕체
sfUICore.loadFont({
    family: 'Black Han Sans',
    src: 'https://fonts.googleapis.com/css2?family=Black+Han+Sans&display=swap',
    weight: 400,
    style: 'normal',
    display: 'swap'
}).then(() => {
    console.log('Local font loaded!');
    document.getElementById('local-font-demo').style.fontFamily = 'Black Han Sans';
});
예제 3: 여러 소스를 가진 폰트 로드 (Fallback)

여러 폰트 형식을 제공하여 브라우저 호환성을 높입니다. 브라우저는 지원하는 첫 번째 형식을 자동으로 선택합니다.

이 텍스트는 Nanum Gothic 폰트로 표시됩니다.
나눔고딕은 한글과 영문을 아름답게 표현합니다.
코드 예제
// 여러 소스를 가진 폰트 로드 (fallback 지원)
sfUICore.loadFont({
    family: 'Nanum Gothic',
    src: [
        { url: '/assets/fonts/nanum-gothic-v21-latin_korean/nanum-gothic-v21-latin_korean-regular.woff2', format: 'woff2' },
        { url: '/assets/fonts/nanum-gothic-v21-latin_korean/nanum-gothic-v21-latin_korean-regular.woff', format: 'woff' },
        { url: '/assets/fonts/nanum-gothic-v21-latin_korean/nanum-gothic-v21-latin_korean-regular.ttf', format: 'truetype' }
    ],
    weight: 400,
    style: 'normal'
}).then(() => {
    console.log('Multi-source font loaded!');
    document.getElementById('multi-source-demo').style.fontFamily = 'Nanum Gothic';
});
예제 4: 여러 폰트를 한 번에 로드

배열을 사용하여 여러 폰트를 동시에 로드할 수 있습니다. 모든 폰트 로드가 완료되면 Promise가 resolve됩니다.

Font 1: Oswald - Bold and Modern Display Font
Font 2: Schibsted Grotesk - Clean and Readable
코드 예제
// 여러 폰트를 배열로 한 번에 로드
sfUICore.loadFont([
    {
        family: 'Oswald',
        src: '/assets/fonts/oswald-v49/oswald-v49-latin-ext_latin_cyrillic-ext_cyrillic-regular.woff2',
        weight: 400
    },
    {
        family: 'Schibsted Grotesk',
        src: '/assets/fonts/Schibsted_Grotesk/static/SchibstedGrotesk-Regular.ttf',
        weight: 400
    }
]).then(() => {
    console.log('All fonts loaded!');
    document.getElementById('multi-font-demo-1').style.fontFamily = 'Oswald';
    document.getElementById('multi-font-demo-2').style.fontFamily = 'Schibsted Grotesk';
});
예제 5: 폰트 프리로드 및 상태 확인

폰트를 백그라운드에서 미리 로드하고, 로딩 상태를 확인하며, 캐시를 관리할 수 있습니다.

상태: 대기 중
코드 예제
// 폰트 프리로드 (백그라운드 로딩)
sfUICore.preloadFonts([
    { family: 'Noto Sans KR', src: 'https://fonts.googleapis.com/...' },
    { family: 'Roboto', src: 'https://fonts.googleapis.com/...' }
]);

// 폰트 로드 상태 확인
if (sfUICore.isFontLoaded('Noto Sans KR', 400, 'normal')) {
    console.log('Font is loaded!');
}

// 폰트 로딩 대기
await sfUICore.waitForFont('Noto Sans KR');

// 로드된 모든 폰트 목록
const loadedFonts = sfUICore.getLoadedFonts();
console.log(loadedFonts);

// 폰트 캐시 초기화
sfUICore.clearFontCache();
예제 6: 사전 로드된 폰트 자동 주입 (NEW v1.1)

HTML에서 미리 로드한 폰트를 sfUI 웹컴포넌트에 자동으로 주입하여 페이지 초기 로딩 시 깜빡임을 완전히 제거합니다.

작동 방식:
  1. HTML <head>에서 Google Fonts 또는 로컬 폰트를 먼저 로드
  2. injectPreloadedFonts()가 document.fonts API로 로드된 폰트 자동 감지
  3. 감지된 폰트를 모든 sfUI 웹컴포넌트(사이드바, 모달 등)에 자동 주입
  4. Shadow DOM 내부에도 폰트가 적용되어 일관된 UI 제공
상태: 준비됨
HTML에서 폰트 사전 로드 (권장 방법)
<!-- ============================================== -->
<!-- ✓ ALREADY IMPLEMENTED in layout.html (lines 13-19) -->
<!-- ============================================== -->

<!-- HTML head에서 폰트 미리 로드 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=block">

<!-- Font Loader - FOUC Prevention Library -->
<link rel="stylesheet" href="/assets/libs/font-loader-1.0.0/font-loader.css">
<script src="/assets/libs/font-loader-1.0.0/font-loader.js"></script>

<!-- ============================================== -->
<!-- Note: 아래 스타일과 스크립트는 예제 설명용입니다.       -->
<!-- Font Loader 라이브러리가 이 기능을 자동으로 제공합니다. -->
<!-- ============================================== -->

<!-- 폰트 로딩 전 페이지 숨김 (Font Loader가 자동 처리) -->
<style id="font-loading-styles">
    html:not(.fonts-ready) body {
        visibility: hidden !important;
    }
    html.fonts-ready body {
        visibility: visible !important;
    }
</style>

<script>
(function() {
    'use strict';

    // 폰트 로딩 완료 후 페이지 표시 및 자동 주입
    const initializePage = () => {
        document.documentElement.classList.add('fonts-ready');

        // 사전 로드된 폰트를 sfUI 컴포넌트에 자동 주입
        if (window.sfUICore) {
            sfUICore.injectPreloadedFonts({
                autoDetect: true,
                important: false
            }).then(result => {
                console.log('✓ Fonts auto-injected:', result);
            });
        }
    };

    // document.fonts.ready를 기다린 후 초기화
    document.fonts.ready.then(initializePage);

    // 폴백: 3초 후 무조건 표시
    setTimeout(() => {
        if (!document.documentElement.classList.contains('fonts-ready')) {
            initializePage();
        }
    }, 3000);
})();
</script>
특정 폰트만 주입하기
// ==============================================
// ✓ ALREADY IMPLEMENTED in layout.html
// Font Loader 라이브러리가 자동으로 처리합니다.
// ==============================================

// 특정 폰트만 sfUI 컴포넌트에 주입
await sfUICore.injectPreloadedFonts({
    targetFont: 'Noto Sans KR',  // 특정 폰트만 선택
    selector: '*',                // 컴포넌트 내 대상 요소
    important: true               // !important 플래그
});

// 또는 자동 주입 (DOM Ready 시 자동 실행)
sfUICore.autoInjectFonts({
    autoDetect: true
});
이 페이지에서 이미 사용 중!

이 데모 페이지는 페이지 로드 시 자동으로 injectPreloadedFonts()를 실행하여 사이드바를 포함한 모든 sfUI 컴포넌트에 Noto Sans KR 폰트를 적용했습니다. 그래서 페이지 로딩 시 깜빡임 없이 일관된 폰트로 표시됩니다.

Best Practice:
  • <link rel="preconnect">로 Google Fonts 서버에 미리 연결
  • 페이지 <head>에서 font-display: block으로 폰트 로드
  • document.fonts.ready를 기다린 후 injectPreloadedFonts() 실행
  • 페이지 visibility를 CSS로 제어하여 폰트 로딩 완료까지 화면 숨김
  • 3초 폴백 타임아웃으로 네트워크 문제 시에도 페이지 표시 보장
  • ✅ 결과: FOUC(Flash of Unstyled Content) 완전 방지!
예제 7: 웹컴포넌트에서 웹폰트 적용

sfUI의 웹컴포넌트(예: sf-sidebar, sf-modal 등)에서도 로드된 웹폰트를 적용할 수 있습니다.

데모: 좌측 사이드바의 폰트가 변경됩니다. 메뉴 텍스트를 확인해보세요!
폰트 선택:
현재 폰트: 기본 폰트
코드 예제 - sfUICore API 사용
// ==============================================
// Note: 웹컴포넌트 폰트 적용 기능
// sfUI 라이브러리에서 제공하는 API입니다.
// ==============================================

// 1. 폰트 로드
await sfUICore.loadFont({
    family: 'Gaegu',
    src: 'https://fonts.googleapis.com/css2?family=Gaegu&display=swap'
});

// 2. 단일 웹컴포넌트에 폰트 적용
const sidebar = document.querySelector('sf-sidebar');
sfUICore.applyFontToComponent(sidebar, 'Gaegu', {
    selector: '*',        // 모든 요소에 적용
    important: true       // !important 플래그 사용
});

// 3. 여러 컴포넌트에 폰트 적용
const components = document.querySelectorAll('sf-sidebar, sf-modal');
sfUICore.applyFontToComponents(components, 'Gaegu');

// 4. 모든 sfUI 웹컴포넌트에 폰트 적용
sfUICore.applyFontToAllComponents('Gaegu');

// 5. 컴포넌트에서 폰트 제거 (기본 폰트로 복원)
sfUICore.removeFontFromComponent(sidebar);

// 6. 모든 컴포넌트에서 폰트 제거
sfUICore.removeFontFromAllComponents();
새로운 API 특징:
  • Shadow DOM 자동 감지 및 처리
  • 여러 컴포넌트 일괄 처리 지원
  • 커스텀 CSS 선택자 지원
  • 에러 핸들링 및 결과 반환
참고: 웹컴포넌트가 Shadow DOM을 사용하는 경우, sfUICore API가 자동으로 Shadow DOM 내부에 스타일을 주입합니다.
API 참조
메서드 설명 반환값
loadFont(fontConfig) 웹폰트를 로드합니다. 단일 객체 또는 배열을 받을 수 있습니다. Promise
isFontLoaded(family, weight, style) 폰트가 이미 로드되었는지 확인합니다. Boolean
waitForFont(family, text, timeout) 폰트가 사용 가능할 때까지 대기합니다. Promise
preloadFonts(fontConfigs) 여러 폰트를 백그라운드에서 로드합니다. Promise
getLoadedFonts() 로드된 모든 폰트의 목록을 반환합니다. Array
clearFontCache() 폰트 캐시를 초기화하고 동적으로 생성된 @font-face 규칙을 제거합니다. void
applyFontToComponent(component, fontFamily, options) [NEW] 웹컴포넌트에 폰트를 적용합니다. Shadow DOM을 자동으로 감지하고 처리합니다. Boolean
applyFontToComponents(components, fontFamily, options) [NEW] 여러 웹컴포넌트에 폰트를 일괄 적용합니다. Object
applyFontToAllComponents(fontFamily, options) [NEW] 페이지의 모든 sfUI 웹컴포넌트에 폰트를 적용합니다. Object
removeFontFromComponent(component) [NEW] 웹컴포넌트에서 커스텀 폰트를 제거하고 기본 폰트로 복원합니다. Boolean
removeFontFromAllComponents() [NEW] 모든 sfUI 웹컴포넌트에서 커스텀 폰트를 제거합니다. Number
injectPreloadedFonts(options) [NEW v1.1] HTML 문서에서 사전 로드된 폰트를 자동으로 감지하여 sfUI 웹컴포넌트에 주입합니다. 페이지 초기 로딩 시 깜빡임 방지에 최적화되어 있습니다. Promise<Object>
autoInjectFonts(options) [NEW v1.1] DOM 준비 시 자동으로 사전 로드된 폰트를 주입합니다. 편의 메서드입니다. Promise<Object>
참고: 폰트 로딩은 비동기 작업입니다. 항상 .then() 또는 await를 사용하여 로딩 완료를 기다린 후 폰트를 적용하세요.
