Common Options Reference
Option Type Default Description
searchEnabled Boolean true Enable/disable search functionality
removeItemButton Boolean false Show remove button for selected items
maxItemCount Number -1 Maximum number of items that can be selected
placeholder Boolean true Show placeholder text
placeholderValue String null Custom placeholder text
searchPlaceholderValue String null Placeholder for search input
shouldSort Boolean true Sort options alphabetically
shouldSortItems Boolean false Sort selected items
delimiter String ',' Delimiter for text input values
editItems Boolean false Allow editing of text input items
addItems Boolean true Allow adding new items
duplicateItemsAllowed Boolean true Allow duplicate items
noResultsText String 'No results found' Text when no results found
itemSelectText String 'Press to select' Text for item selection prompt
Common API Methods
Method Description Example
getValue() Get selected value(s) choice.getValue(true)
setValue() Set value(s) choice.setValue(['value1', 'value2'])
setChoices() Set available choices choice.setChoices([{value:'1', label:'One'}])
clearStore() Clear all options choice.clearStore()
clearInput() Clear input value choice.clearInput()
disable() Disable the input choice.disable()
enable() Enable the input choice.enable()
removeActiveItems() Remove all selected items choice.removeActiveItems()
destroy() Destroy the instance choice.destroy()
Available Events
Event Description When Triggered
addItem Item added to selection When user selects an item
removeItem Item removed from selection When user removes an item
highlightItem Item highlighted When user hovers over an item
unhighlightItem Item unhighlighted When hover leaves an item
choice Choice selected from dropdown When a choice is selected
change Value changed When the value changes
search User searches When typing in search box
showDropdown Dropdown shown When dropdown opens
hideDropdown Dropdown hidden When dropdown closes
