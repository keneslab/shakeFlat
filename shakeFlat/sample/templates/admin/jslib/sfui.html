Complete API Reference
Alert API
Method Parameters Description
sfUI.alert.sfAlert() message, [callback] Show alert dialog
sfUI.alert.sfNoti() message, [callback] Show notification
sfUI.alert.sfConfirm() message, [yesCallback], [noCallback] Show confirm dialog (supports Promise)
sfUI.alert.sfInputConfirm() message, callback, [options] Show input dialog
sfUI.alert.sfAlertBack() message Show alert and go back in history
sfUI.alert.show() options Show alert with custom options (see below)
Options for sfUI.alert.show():
  • closeOnBackdropClick (boolean): Allow closing by clicking backdrop. Default: true
  • type (string): 'alert', 'confirm', or 'input'
  • messageText (string): The message to display
  • alertType (string): 'default', 'danger', 'warning', 'info', 'success'
  • fontSize (string): Custom font size (e.g., '1.5rem')
  • width (string): Custom width (e.g., '500px')
Modal API
Method Parameters Description
sfUI.modal.create() id, options Create modal instance
modal.show() - Show the modal
modal.hide() - Hide the modal
modal.setBody() html Update modal body
modal.setTitle() title Update modal title
modal.getBody() - Get body element
modal.getHeader() - Get header element
modal.getFooter() - Get footer element
Key Options for sfUI.modal.create():
  • closeOnBackdropClick (boolean): Allow closing by clicking backdrop. Default: true
  • title (string): Modal title
  • verticalCenter (boolean): Center modal vertically. Default: true
  • animation (boolean): Enable fade animation. Default: true
  • header.close (boolean): Show close button in header. Default: true
LightBox API
Method Parameters Description
sfUI.lightbox.init() selector, [options] Initialize lightbox
sfUI.lightbox.open() gallery, imageSrc Open specific image
sfUI.lightbox.close() - Close lightbox
RangeSlider API
Method Parameters Description
sfUI.rangeslider.init() selector, options Initialize range slider
apply.sfrangeslider event Event fired when range applied
Notice Board API
Component Attributes Description
<sf-notice> type, color, title, message Display notice board with different styles and colors
type="notice" - Blue style for important notices (type-based)
type="hint" - Cyan/teal style for hints and tips (type-based)
type="plain" - Gray style for general information (type-based)
color="primary" - NEW Blue theme (Bootstrap color)
color="success" - NEW Green theme (Bootstrap color)
color="danger" - NEW Red theme (Bootstrap color)
color="warning" - NEW Yellow theme (Bootstrap color)
color="info" - NEW Cyan theme (Bootstrap color)
updateTheme() - Method to manually update theme (auto-called)
Utility API
Method Parameters Description
sfUI.formatNumber() num, decimals, decPoint, thousandsSep Format number with separators
sfUI.formatNumberShort() num Format to K/M/B notation
sfUI.getTheme() - Get current theme
sfUI.setTheme() theme Set theme ('light'/'dark')
sfUI.toggleTheme() - Toggle between themes
sfUI.onThemeChange() callback Listen to theme changes
sfUI.getLanguage() - Get current language
sfUI.setLanguage() lang Set language ('ko'/'en')

Bootstrap 5 Compatibility
Fully Compatible! sfUI uses unique class names prefixed with sfui- to avoid conflicts with Bootstrap.

Key Features:

  • All classes use sfui- prefix (e.g., .sfui-modal, .sfui-btn)
  • Automatic integration with Bootstrap's data-bs-theme system
  • Detects and synchronizes with Bootstrap theme changes
  • Can be used alongside Bootstrap modals and components without conflicts
  • Leverages Bootstrap color variables for consistency
