🎨 sfUI

Unified UI Component Library v1.0.0

Vanilla JavaScript • Zero Dependencies • Modern Design

📢 Alert Component

Beautiful alert, notification, confirm, and input dialogs

sfUI.alert.sfAlert('Hello World!');
// Callback style
sfUI.alert.sfConfirm('Sure?', yesCallback, noCallback);
// Promise style (like native confirm)
if (await sfUI.alert.sfConfirm('Sure?')) { ... }
// Inline if statement - most intuitive!
if (await confirm('Delete?')) { deleteItem(); }
sfUI.alert.sfInputConfirm('Name?', callback);

🪟 Modal Component

Reusable modal dialogs with customizable content

const modal = sfUI.modal.create('myModal', { title: 'Title', body: { html: 'Content' } });
modal.show();
modal.setBody('New content');

🖼️ LightBox Component

Image gallery with smooth transitions and keyboard navigation

<img data-sflightbox="gallery1" data-caption="Caption" src="image.jpg">
sfUI.lightbox.init('[data-sflightbox]');

🎚️ RangeSlider Component

Interactive range slider for number inputs

<input data-sfrangeslider data-min="0" data-max="1000000" data-prefix="$">
sfUI.rangeslider.init('#input', { min: 0, max: 1000000, prefix: '$' });

📋 Sidebar

Responsive sidebar menu component with full, mini, and hide modes

<sf-sidebar menu-src="/menu.json" mode="full" theme="light"></sf-sidebar>
const sidebar = sfUI.sidebar.create('#container', { menuSrc: '/menu.json' });
sfUI.sidebar.setMode(sidebar, 'mini'); // 'full', 'mini', 'hide'
sfUI.sidebar.toggleLock(sidebar);

Note: The sidebar component is best demonstrated in a full layout. Check the SF-SIDEBAR-README.md for complete examples.

Menu JSON Structure: 

{
  "menu": [
    {
      "title": "Dashboard",
      "icon": "bi-speedometer2",
      "link": "/dashboard"
    },
    {
      "title": "Users",
      "icon": "bi-people",
      "sub": [
        { "title": "List", "link": "/users/list" },
        { "title": "Add", "link": "/users/add" }
      ]
    }
  ]
}

🛠️ Utilities

Helper functions for common tasks

sfUI.formatNumber(1234567.89, 2, '.', ','); // "1,234,567.89"
