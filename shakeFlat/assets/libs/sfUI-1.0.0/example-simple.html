📦 Simple Icon Font Demo

✅ Bootstrap Icons과 FontAwesome이 자동으로 주입되었습니다!

왼쪽 사이드바를 확인해보세요:

  • 메뉴 아이콘들이 표시됩니다 (Bootstrap Icons)
  • 서브메뉴를 펼치면 화살표가 표시됩니다 (FontAwesome)

사용된 코드:

// 아이콘 폰트 주입
await sfUICore.injectIconFonts([
    { cssUrl: '../bootstrap-icons-1.13.1/font/bootstrap-icons.min.css' },
    { cssUrl: '../fontawesome-free-7.1.0-web/css/all.min.css' }
]);

// 사이드바 메뉴 설정
sidebar.setMenuData([
    { title: 'Dashboard', icon: 'bi-speedometer2', link: '#' },
    { title: 'Content', icon: 'bi-file-text', sub: [...] }
]);
