Code Example

아이콘 폰트를 주입하는 코드:

// Bootstrap Icons + FontAwesome 주입
await sfUICore.injectIconFonts([
    {
        cssUrl: '/assets/libs/bootstrap-icons-1.13.1/font/bootstrap-icons.min.css'
    },
    {
        cssUrl: '/assets/libs/fontawesome-free-7.1.0-web/css/all.min.css'
    }
]);
